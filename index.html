Your file share

Provision your personal Azure file share and connect it as a network drive on Windows.

How to connect on Windows

1

Open "Map network drive"

In File Explorer, click This PC → top menu Computer → Map network drive. Choose any drive letter (e.g. Z:).

2

Enter your share path

Paste this into the Folder field and tick Connect using different credentials.

\\smbclouddrive.file.core.windows.net\your-share
3

Enter credentials when prompted

Username:

AZURE\smbclouddrive

Storage account key (password):

••••••••••••••••••••••••••••••••
4

Check port 445 if connection fails

SMB requires port 445 outbound. Test it in PowerShell:

Test-NetConnection -ComputerName smbclouddrive.file.core.windows.net -Port 445

If TcpTestSucceeded is False, port 445 is blocked by your ISP or firewall.

Your share is ready. Once mapped, it will appear as a network drive in File Explorer and you can drag and drop files just like a local drive.
